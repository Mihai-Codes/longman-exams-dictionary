Compatible software applications

Note: this page describes the original Windows CD-ROM feature. Pop Up Mode is not part of this Mac app.

The applications you can use with Web/email Pop Up Mode are as follows:

On Windows 98/ ME/ NT/ Win 2000/ XP

Word 2000, Word XP, Internet Explorer 5+: Move mouse over a word, press Ctrl key.

Word 97, Acrobat Reader, Notepad, Wordpad, Outlook: Highlight a word or phrase, press Ctrl key

**Note that the application (e.g. Word or Internet Explorer) has to be active. You can make it active by clicking into the window.
